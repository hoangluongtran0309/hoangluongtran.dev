= About

// Newsletter signup form is added in the layout (see
// layouts/_default/list.html, `eq .Section "about"` branch), not here.
I'm a software engineer building backend services with Java and Spring Boot.

My day-to-day work revolves around building and maintaining server-side
services: designing APIs, working with JPA/Hibernate and Spring Security, and
writing tests around the parts most likely to break.

This blog is where I write down what I learn along the way — mostly Spring Boot
and the wider Java ecosystem: patterns that hold up, the places I trip over, and
the reasoning behind a technical choice.

All opinions on this blog are my own.
